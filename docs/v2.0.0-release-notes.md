# 鼠须管控制面板 · Squirrel Panel v2.0.0

憋了很久的一次大版本。这一版把界面、配色、纠错三件大事一次做完，并在 macOS 27 上做了完整验证。

---

## 一、回归苹果原生界面

之前为了在 macOS 27 上避开界面 bug，着急发版，曾把界面改成完全自绘的 HStack 布局。但心里一直念念不忘——**还是想用苹果系统原生的界面**。

这一版花了很长时间，把界面重新搬回 `NavigationSplitView` 原生结构，并且在 macOS 27 上反复测试：

- ✅ 消除了此前 macOS 27 下侧边栏顶部的灰色折叠胶囊占位
- ✅ 消除了 detail 区域顶部那条半透明暗条
- ✅ 标题栏出现系统原生的侧边栏切换按钮，行为符合系统预期

现在界面既是苹果原生骨架，又在最新系统上干干净净。

---

## 二、侧边栏重构

顺着调界面 UI，我把侧边栏重新规划了一遍：

- 那只等着起名的小耗子（应用图标）
- 版本号
- **最重要的「应用并重新部署」按钮**

全部收进了侧边栏。操作路径更短，主区域更专注。

应一位实际使用朋友的需求，这一版把「用户自定义配色」模块的能力加强了：

- 方案列表可以容纳更多方案，不再局促
- **深色模式配色下拉列表里也可以直接选中**自定义方案

## 四、Bug 修复

这一版一并修掉了一批老问题：

- **外观面板卡顿**：根因是字体族（474 项）在首帧同步构建阻塞。改为 popover + 懒加载搜索后，切换面板不再卡顿。
- **取消自动备份**：之前每次「应用并重新部署」都会自动生成一个 `.bak` 备份，时间久了很占地方。这一版改为**纯手动备份**，你需要时才备份。

![备份与同步](https://raw.githubusercontent.com/wolfprince12/squirrel-Panel/main/docs/v2.0.0-backup-sync.png)

## 五、输入方案可单独删除

一个小功能，但对有洁癖的人很重要。

非鼠须管本身自带的输入方案，现在可以**单独删除**了。这主要也是我自己的需求——五笔、繁体、双拼、九笔这些我完全不用的方案，再也不用硬留在电脑里。

## 六、紫毫纠错模型（重点）

这是这一版最重要的东西。

之前我先试着把 AI-Rime 融合进来，但鼠须管的核心精神是**不联网**。我设计了一套用 Python + MLX 驱动、加载本地大模型来做 AI 增强的方案，折腾了整整三天。

结果很残酷：AI 纠错的速度就是达不到我想要的「随手感」，总有延迟。以我的打字速度，这种带延迟的纠错对我**完全没意义**。

痛定思痛，我把做了三天的 AI 增强代码**全删了**，重新理清头绪：百度输入法、搜狗输入法、微信输入法，它们怎么做纠错？**都没用 AI**——因为「输入字母 → 引擎驱动 → 投喂大模型 → 大模型推理 → 返回词语」这一段，逻辑上就很难做到实时。

所以我参考商业大厂的做法，做了这个 **紫毫纠错模型（Amethyst Correction Model）**：

- 在鼠须管本身的**模糊音**基础上，配合**万象语法模型**的词频预判
- 用**最少的代码** + 一个**精简过的词典**
- 做到**零延迟、随手出**的纠错
- 覆盖**临近错键**和**相近音混淆**两类纠错场景

基于鼠须管的设计精神，这个纠错功能必须是**可控的**：可以开关，可以调整纠错词语出现的位置和数量。

![紫毫纠错模型](https://raw.githubusercontent.com/wolfprince12/squirrel-Panel/main/docs/v2.0.0-amethyst-correction.png)

大家可以试试看。

## 安装

1. 下载下方 `Squirrel-Panel-2.0.0.dmg`
2. 打开 DMG，把 `Squirrel Panel.app` 拖进「应用程序」（应用名随系统语言：Squirrel Panel / 鼠须管控制面板 / 鼠鬚管控制面板）
3. 首次打开若提示「无法打开」，去 **系统设置 → 隐私与安全性** 点「仍要打开」

> 确保你的 Mac 已安装鼠须管输入法（[官方下载](https://rime.im/download/)）。

## 校验

- 构建产物：`make dmg`（release 构建，原生 arm64）
- Lua 资源：随构建通过 `check-lua` 做 Lua 5.1 语法校验
- 二进制已 `xattr -cr` + ad-hoc `codesign`
